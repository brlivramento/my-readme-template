
# My README Templates

My personal collection of reusable README templates for software projects.

A consistent and minimal approach to documenting applications, APIs, experiments, and technical projects.

## Templates

| Template | Description |
| --- | --- |
| [Minimal](./templates/minimal.md) | Small projects, experiments, and legacy applications |
| [Standard](./templates/standard.md) | Web applications, dashboards, and personal projects |
| [Advanced](./templates/advanced.md) | REST APIs, integrations, and complex architectures |

## Guidelines

- Keep descriptions short and objective
- Document only relevant technologies
- Use architecture diagrams when necessary
- Prefer reproducible setup instructions
- Include screenshots for visual applications
- Include endpoints and examples for APIs
- Use dynamic badges for automated checks
- Remove sections that do not apply

## Usage

1. Choose the appropriate template.
2. Copy its contents into your project's `README.md`.
3. Replace example values with actual project information.
4. Remove unnecessary sections.
5. Keep the documentation updated as the project evolves.

## Conventions

- Language: English
- Format: Markdown
- Diagrams: Mermaid
- Badges: Shields.io
- Screenshots: GitHub attachments or local assets
- Setup: Docker Compose when applicable
